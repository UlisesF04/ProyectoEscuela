# Run and deploy your AI Studio app

Historical AI Studio design reference. Its source files remain in `Diseño Front/` at the repository root. For the school application, use the [main README](../../README.md).

View your app in AI Studio: https://ai.studio/apps/a9eb1f74-8d27-4ea8-8fbe-37fe30d6f7bc

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. In the prototype's source directory, set `GEMINI_API_KEY` in `.env.local` to your Gemini API key.
3. Run the app:
   `npm run dev`
