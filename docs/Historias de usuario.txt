MÓDULO 1: AUTENTICACIÓN Y ACCESO
================================================================================

    HU-001: Inicio de sesión
    Como usuario del sistema (empleado, docente, preceptor o administrador),
    quiero poder iniciar sesión con mi email y contraseña, para acceder a las
    funcionalidades correspondientes a mi rol de forma segura.

    Estado: [x] COMPLETADO — 2026-05-15

    CA:
        [ ] El sistema valida email y contraseña contra la base de datos.
        [ ] Si las credenciales son correctas, se genera un token JWT.
        [ ] Si las credenciales son incorrectas, se muestra un mensaje de
            error genérico.
        [ ] El token JWT expira en 8 horas.
        [ ] El acceso a rutas protegidas sin token devuelve error 401.
    RN: RN-08

    ─────────────────────────────────────────────────────────────────────

    HU-002: Cierre de sesión
    Como usuario autenticado, quiero poder cerrar mi sesión, para proteger
    mi cuenta en equipos compartidos.

    Estado: [x] COMPLETADO — 2026-05-15

    CA:
        [ ] Al hacer logout, el token se invalida o elimina del cliente.
        [ ] El usuario es redirigido a la pantalla de login.
    RN: RN-08

    ─────────────────────────────────────────────────────────────────────

    HU-003: Recuperación de contraseña
    Como usuario del sistema, quiero poder recuperar mi contraseña vía
    email, para no perder el acceso a mi cuenta si la olvido.

    Estado: [ ] PENDIENTE (pospuesto — requiere email service)

    CA:
        [ ] El sistema envía un email con un link de recuperación de
            vigencia 1 hora.
        [ ] El link expirado muestra un mensaje de error claro.

MÓDULO 2: GESTIÓN DE INASISTENCIAS
================================================================================

    HU-004: Registro de inasistencias diarias
    Como empleado administrativo o preceptor, quiero registrar las
    inasistencias de los alumnos de un curso en el día actual, para mantener
    un registro preciso y actualizado de la asistencia escolar.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Puedo seleccionar un curso y ver el listado de alumnos.
        [ ] Puedo marcar uno o varios alumnos como ausentes.
        [ ] Solo puedo cargar inasistencias del día actual o del día hábil
            anterior.
        [ ] Una vez guardado, el sistema confirma el registro con mensaje
            de éxito.
        [ ] No se permite cargar inasistencias de más de 2 días hábiles
            atrás.
    RN: RN-03

    ─────────────────────────────────────────────────────────────────────

    HU-005: Visualización del historial de inasistencias por alumno
    Como empleado, docente o preceptor, quiero consultar el historial de
    inasistencias de un alumno específico, para hacer un seguimiento de su
    regularidad.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Puedo buscar un alumno por nombre o DNI.
        [ ] Se muestra el total de inasistencias en el año y el porcentaje
            sobre clases dictadas.
        [ ] Se discrimina visualmente entre inasistencias justificadas y
            no justificadas.
        [ ] Se indica visualmente si el alumno está en riesgo de perder
            la regularidad (>20%).
    RN: RN-02, RN-13

    ─────────────────────────────────────────────────────────────────────

    HU-006: Edición de inasistencias registradas
    Como empleado administrativo o preceptor, quiero poder corregir una
    inasistencia cargada por error, para mantener la integridad de los datos.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Solo puedo editar registros del día actual o del día hábil
            anterior.
        [ ] Toda edición queda registrada con el usuario que la realizó y
            la fecha/hora.
    RN: RN-03

    ─────────────────────────────────────────────────────────────────────

    HU-019: Justificación de inasistencias
    Como preceptor o administrativo, quiero poder marcar una inasistencia
    como justificada y asociarla a un certificado, para distinguirla de las
    no justificadas en todos los reportes.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Puedo cambiar el estado de una inasistencia a "justificada".
        [ ] El campo acepta una referencia al certificado ya cargado en el
            sistema o se puede adjuntar uno nuevo.
        [ ] Las inasistencias justificadas se muestran con distinción visual
            en historial, tablero y reportes.
        [ ] El cambio queda auditado con usuario y timestamp.
    RN: RN-13

MÓDULO 3: GESTIÓN DE CALIFICACIONES Y TAREAS
================================================================================

    HU-007: Carga de calificaciones
    Como docente, quiero cargar las calificaciones de mis alumnos por
    materia y período, para que queden registradas y disponibles para
    consulta y alertas automáticas.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Solo puedo cargar calificaciones en las materias que tengo
            asignadas.
        [ ] Las notas deben ser numéricas, entre 1 y 10.
        [ ] Al guardar una nota <= 4, el sistema la marca para generar
            alerta (RN-04).
        [ ] Se muestra confirmación al guardar correctamente.
    RN: RN-04, RN-05

    ─────────────────────────────────────────────────────────────────────

    HU-008: Visualización del promedio general de alumnos
    Como docente, quiero ver el promedio general de cada alumno en mi
    materia, para identificar rápidamente quiénes necesitan apoyo.

    Estado: [ ] PENDIENTE

    CA:
        [ ] La vista muestra la lista de alumnos con su promedio calculado.
        [ ] Los alumnos con promedio < 6 se resaltan visualmente.
    RN: RN-05

    ─────────────────────────────────────────────────────────────────────

    HU-009: Registro de tareas asignadas y estado de entrega
    Como docente, quiero registrar tareas asignadas e indicar si cada
    alumno la entregó o no, para hacer seguimiento de los compromisos
    académicos.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Puedo crear una tarea con nombre, fecha de asignación y fecha
            de entrega.
        [ ] Puedo marcar el estado de entrega de cada alumno
            (entregado / no entregado).
        [ ] Cuando un alumno acumula 2 tareas no entregadas consecutivas,
            se genera alerta.
    RN: RN-06

MÓDULO 5: NOTIFICACIONES AUTOMÁTICAS (AGENTE / BOT)
================================================================================

    HU-012: Notificación automática por inasistencias reiteradas
    Como padre/tutor, quiero recibir una notificación por WhatsApp cuando
    mi hijo acumule 3 inasistencias en el mes, para enterarme oportunamente
    y poder actuar.

    Estado: [ ] PENDIENTE

    CA:
        [ ] El mensaje incluye nombre del alumno, cantidad de inasistencias
            y fecha.
        [ ] La notificación se envía una única vez por día ante la misma
            condición (RN-11).
        [ ] Se envía al número de WhatsApp registrado del tutor.
    RN: RN-01, RN-11

    ─────────────────────────────────────────────────────────────────────

    HU-013: Notificación por riesgo de pérdida de regularidad
    Como padre/tutor, quiero recibir una alerta cuando mi hijo esté en
    riesgo de perder la regularidad, para tomar medidas antes de que sea
    tarde.

    Estado: [ ] PENDIENTE

    CA:
        [ ] La alerta indica el porcentaje de inasistencias acumuladas y
            el límite permitido.
        [ ] Se envía al superar el 20% de inasistencias sobre el total de
            clases dictadas.
    RN: RN-02, RN-11

    ─────────────────────────────────────────────────────────────────────

    HU-014: Notificación por calificación baja
    Como padre/tutor, quiero ser notificado cuando mi hijo obtenga una nota
    <= 4 en cualquier materia, para poder apoyarlo a tiempo.

    Estado: [ ] PENDIENTE

    CA:
        [ ] El mensaje incluye nombre del alumno, materia y nota obtenida.
        [ ] No se envía más de una notificación por evento por día.
    RN: RN-04, RN-11

    ─────────────────────────────────────────────────────────────────────

    HU-015: Notificación por tareas no entregadas
    Como padre/tutor, quiero recibir una alerta cuando mi hijo no entregue
    2 tareas consecutivas en la misma materia, para hacer el seguimiento
    de sus compromisos escolares.

    Estado: [ ] PENDIENTE

    CA:
        [ ] El mensaje indica la materia y el nombre de las tareas
            pendientes.
    RN: RN-06, RN-11

    ─────────────────────────────────────────────────────────────────────

    HU-016: Notificación de vencimiento de licencias docentes
    Como docente, quiero recibir una alerta cuando me queden 3 o menos días
    de licencia, para planificar con anticipación.

    Estado: [ ] PENDIENTE

    CA:
        [ ] El mensaje indica los días restantes disponibles.
        [ ] Se envía al número de WhatsApp o email registrado del docente.
    RN: RN-07, RN-11

    ─────────────────────────────────────────────────────────────────────

    HU-017: Registro y trazabilidad de notificaciones enviadas
    Como administrador del sistema, quiero que todas las notificaciones
    enviadas queden registradas en la base de datos, para auditar el
    funcionamiento del bot y evitar duplicados.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Se registra: destinatario, tipo de alerta, fecha/hora de envío,
            estado (éxito/fallo).
        [ ] El agente consulta este registro antes de enviar para aplicar
            RN-11.
    RN: RN-11

MÓDULO 7: ANALÍTICA Y TABLERO DE EVOLUCIÓN
================================================================================

    HU-020: Tablero de analítica de asistencias
    Como padre/tutor, docente, preceptor o administrador, quiero visualizar
    la evolución de inasistencias del alumno en un tablero gráfico, para
    identificar tendencias y actuar antes de que el problema se agrave.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Se muestra el total de inasistencias del año con desglose
            mensual.
        [ ] Se distinguen visualmente las justificadas de las no
            justificadas en todos los gráficos.
        [ ] Se muestra una alerta visual cuando se superan los umbrales
            de RN-01 (3/mes) y RN-02 (20% anual).
        [ ] Puedo ver las inasistencias más recientes en una lista
            cronológica con estado (justificada / no justificada).
        [ ] El acceso está limitado al alcance de cada rol (RN-16).
    RN: RN-12, RN-13, RN-16

    ─────────────────────────────────────────────────────────────────────

    HU-021: Tablero de analítica de calificaciones
    Como padre/tutor, docente o administrador, quiero visualizar la
    evolución de las calificaciones del alumno, para entender su progreso
    académico por materia y por período.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Se muestra el promedio general y el promedio por materia.
        [ ] Puedo filtrar las notas por materia y por trimestre.
        [ ] Se presenta un gráfico de evolución de notas a lo largo
            del tiempo.
        [ ] Se resaltan visualmente las materias con promedio < 6 y
            las notas individuales <= 4.
        [ ] El tablero es accesible según el rol del usuario (RN-16).
    RN: RN-12, RN-16

    HU-022: Envío de mensajes a personal de la institución
    Como padre/tutor, quiero poder enviar un mensaje al docente, preceptor
    o secretaría desde el portal, para comunicarme con la institución sin
    necesitar concurrir personalmente.

    Estado: [ ] PENDIENTE

    CA:

        [ ] No puedo enviar mensajes a otras familias.
        [ ] Recibo una confirmación visual al enviar correctamente.
    RN: RN-14

    ─────────────────────────────────────────────────────────────────────

    Como docente, preceptor o administrativo, quiero ver y responder los
    mensajes que recibo de las familias, para gestionar la comunicación
    desde un único panel.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Veo la lista de conversaciones con estado (leído / no leído).
        [ ] Puedo responder a cada mensaje desde el mismo hilo.
        [ ] Al leer un mensaje, su estado cambia a "leído" con timestamp.
        [ ] Puedo filtrar por estado (pendiente / respondido).
    RN: RN-14

MÓDULO 9: CERTIFICADOS DIGITALES
================================================================================

    HU-024: Carga de certificado de justificación
    Como padre/tutor, quiero poder cargar un certificado (imagen o PDF)
    desde el portal, para justificar digitalmente la inasistencia de mi
    hijo sin tener que llevar el papel físicamente.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Puedo subir un archivo imagen (JPG, PNG) o PDF de hasta 5MB.
        [ ] El certificado queda asociado al alumno y al período indicado.
        [ ] El estado inicial del certificado es "pendiente de revisión".
        [ ] Recibo una confirmación visual con el estado del envío.
    RN: RN-15

    ─────────────────────────────────────────────────────────────────────

    HU-025: Validación de certificados por personal autorizado
    Como preceptor o administrativo, quiero poder revisar los certificados
    presentados y aceptarlos o rechazarlos, para mantener un registro
    formal de las justificaciones con trazabilidad.

    Estado: [ ] PENDIENTE

    CA:
        [ ] Veo la lista de certificados pendientes con nombre del alumno,
            fecha y período asociado.
        [ ] Puedo previsualizar el archivo subido.
        [ ] Puedo marcar el certificado como "aceptado" o "rechazado"
            opcionalmente con un comentario.
        [ ] La resolución queda registrada con fecha, usuario y resultado.
        [ ] Al aceptar un certificado, la inasistencia asociada se marca
            automáticamente como justificada (RN-13).
    RN: RN-15, RN-13
